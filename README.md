# Event Management System

A full-stack Event Management System designed to simplify event planning, organization, and management through a centralized web application.

## Overview

The Event Management System provides a platform for managing event-related activities. It organizes the frontend, backend, and project documentation into separate modules to support structured development and maintenance.
